90S Thai ROM Studio

แกะข้อความอังกฤษ ญี่ปุ่น จีน เกาหลี และภาษายุโรปจากรอมเกม GBA, แผ่น PS1, Nintendo และเครื่องอื่น แปลเป็นไทย ใส่กลับ สร้างแพตช์ ใส่เครดิตเพจในเกม และทำปกเกม ทุกอย่างทำงานในเครื่องคุณ ไฟล์รอมไม่ถูกส่งไปที่ไหน

ระบบที่รองรับ (ครอบคลุมเครื่องเล่น R36S)
  • ย้ายข้อความและขยายรอมได้: Game Boy Advance, Mega Drive / Genesis
  • ย้ายข้อความได้ในที่ว่างของไฟล์: PlayStation (.bin / .iso), Nintendo DS, Neo Geo Pocket, Virtual Boy
  • แปลแบบลงที่เดิม พร้อมแก้ checksum: Game Boy / Color, Super Famicom, Master System, Game Gear, WonderSwan
  • แปลแบบลงที่เดิม: Famicom / NES, Famicom Disk System, Nintendo 64, PC Engine, Atari 2600 / 7800 / Lynx, ColecoVision, MSX, SG-1000, Pokemon Mini
  • ชุดรอม .zip (อาร์เคด FBNeo / MAME, Neo Geo, CPS): เปิด .zip แล้วเลือกไฟล์รอมข้างในมาแปล บันทึกกลับเป็น .zip ได้ รอม 68000 ส่วนใหญ่ต้องติ๊ก "สลับไบต์คู่" อีมูเลเตอร์จะเตือนว่า CRC ไม่ตรงกับฐานข้อมูล
  • แผ่น PSP และแผ่น .iso อื่น: เปิดดูและแปลไฟล์ข้างในได้ถ้าไฟล์นั้นไม่เข้ารหัสหรือบีบอัด
  • ต้องแปลงก่อน: .chd .cso .pbp และแผ่น Dreamcast (.gdi / .cdi) ให้แปลงเป็น .bin หรือ .iso ก่อนเปิด

ไฟล์ในแผ่น

แกะข้อความจากรอม

ข้อความที่มีพอยน์เตอร์ชี้มักเป็นบทพูดและเมนูจริง และย้ายที่ได้เมื่อคำแปลยาวกว่าเดิม ถ้าเกมไม่ได้เก็บข้อความเป็น ASCII ให้ไปตั้งตารางอักษรก่อน เกมญี่ปุ่นของ PS1 และ GBA หลายเกมเก็บข้อความเป็น Shift-JIS เลือกภาษาต้นฉบับเป็นญี่ปุ่นแล้วกดแกะได้เลย ส่วนเกมญี่ปุ่นของ Famicom, Super Famicom และ Game Boy มักใช้รหัสอักษรของตัวเอง ต้องทำตารางอักษร (.tbl) ก่อน

ตั้งค่าปุ่ม "ให้ Claude แปลหน้านี้"

ในโปรแกรม .exe .apk และไฟล์ .html ปุ่มนี้ส่งข้อความในหน้าที่เปิดอยู่ไปให้ Claude แปลผ่านอินเทอร์เน็ต ต้องใช้ API key ของคุณเอง สร้างได้ที่ platform.claude.com มีค่าใช้จ่ายตามปริมาณที่ใช้ และคิดแยกจากแพ็กเกจสมาชิก Claude คีย์ถูกเก็บไว้ในเครื่องนี้เท่านั้น และถูกส่งไปที่ api.anthropic.com ที่เดียว

แปลออฟไลน์ด้วยโมเดล (อังกฤษเป็นไทย)

แปลทั้งประโยคในเครื่องนี้โดยไม่ใช้อินเทอร์เน็ต ครั้งแรกให้กด "เลือกไฟล์โมเดล" แล้วเลือกไฟล์ทั้งหมดในโฟลเดอร์ model-en-th (กด Ctrl+A ในหน้าต่างเลือกไฟล์) โปรแกรมจะจำโมเดลไว้ในเครื่อง ครั้งต่อไปกดปุ่มแปลได้เลย ใช้หน่วยความจำประมาณ 500 MB

โมเดล QuickMT en-th (quickmt/quickmt-en-th) สัญญาอนุญาต CC BY 4.0 แปลงเป็น ONNX โดย KaoJai.ai

แปลหน้านี้ด้วย Google Translate (ต้องต่ออินเทอร์เน็ต)

แบบฟรี: กดลิงก์ด้านล่างเพื่อเปิด Google Translate พร้อมข้อความที่ยังไม่แปลในหน้านี้ คัดลอกคำแปลทั้งหมดกลับมาวางในช่อง แล้วกด "ใส่คำแปลที่วาง" ข้อความหนึ่งรายการคือหนึ่งบรรทัด เครื่องหมาย ¶ แทนการขึ้นบรรทัดใหม่ในเกม อย่าลบออก

เปิด Google Translate

แบบอัตโนมัติ: ถ้ามี API key ของ Google Cloud Translation ใส่ไว้ที่นี่ ปุ่ม Google Translate จะแปลและเติมให้เองโดยไม่ต้องคัดลอกวาง Google คิดค่าบริการตามจำนวนตัวอักษร คีย์ถูกเก็บในเครื่องนี้เท่านั้น

พจนานุกรมของคุณ

บรรทัดละคู่ คำต้นฉบับ=คำแปล ใช้ได้กับทุกภาษา เช่นชื่อตัวละคร ชื่อท่า ศัพท์เฉพาะของเกม โปรแกรมใช้คำเหล่านี้เติมคำแปลและแสดงคำแนะนำใต้แต่ละข้อความ โดยไม่ต้องต่ออินเทอร์เน็ต

คำแปลจากงานเก่า

นำเข้าไฟล์ CSV หรืองานแปล (.json) ที่เคยทำ โปรแกรมจะจำคู่ต้นฉบับกับคำแปลไว้ เมื่อเกมใหม่มีข้อความเดียวกันจะเติมให้ทันที เหมาะกับเกมภาคต่อหรือเกมจากผู้สร้างเดียวกัน

แปลตอนออฟไลน์ทำอะไรได้บ้าง

  • ปุ่ม "เติมคำแปลอัตโนมัติ" ในแท็บข้อความ เติมข้อความที่ตรงกับพจนานุกรม งานเก่า หรือข้อความซ้ำที่แปลไว้แล้วในเกมเดียวกัน
  • ปุ่ม "แปลร่างหน้านี้" แปลประโยคอังกฤษแบบคำต่อคำจากคลังคำในตัว ได้ความหมายคร่าว ๆ แต่ไม่เป็นธรรมชาติเท่า Claude ต้องอ่านและเกลาทุกข้อความ ชื่อเฉพาะที่ไม่รู้จักจะคงไว้ตามเดิม
  • ใต้ข้อความที่ยังไม่แปลจะมีคำศัพท์ที่พบในประโยคให้ดูประกอบ
  • ถ้าต้องการคำแปลที่อ่านลื่นทั้งประโยค ใช้ปุ่ม "ให้ Claude แปลหน้านี้" ซึ่งต้องต่ออินเทอร์เน็ต หรือส่งออก CSV ไปแปลแล้วนำเข้ากลับ

ตารางอักษร (.tbl)

บรรทัดละคู่ ไบต์=ตัวอักษร เช่น A1=ก ค่าเริ่มต้นคือ ASCII และอักษรไทยแบบ TIS-620 (A1–FB) แก้ให้ตรงกับตำแหน่งที่ฟอนต์ไทยอยู่ในเกม ไบต์ที่ไม่อยู่ในตารางจะแสดงเป็น <XX> และพิมพ์แบบเดียวกันในคำแปลได้

หาการเข้ารหัสของเกม

ถ้าแกะแล้วไม่เจอข้อความ เกมอาจใช้รหัสอักษรของตัวเอง พิมพ์คำที่เห็นในเกม (ตัวพิมพ์เดียวกันทั้งคำ อย่างน้อย 3 ตัว เช่น START) โปรแกรมจะหาลำดับไบต์ที่มีระยะห่างระหว่างตัวอักษรตรงกัน

ดูกราฟิกและฟอนต์ในรอม

คลิกที่ช่องเพื่อดูตำแหน่ง

เลื่อนหาจนเห็นตัวอักษร A B C ของเกม ถ้าเห็นแต่จุดมั่ว ลองเปลี่ยนจำนวนสีหรือขนาดช่อง ฟอนต์ที่ถูกบีบอัด (LZ77) จะมองไม่เห็นตรงนี้และต้องแก้เฉพาะเกม

วาดฟอนต์ไทยลงรอม

ใช้ได้กับฟอนต์ที่ไม่บีบอัดและทุกช่องขนาดเท่ากัน ใส่ตำแหน่งที่ฟอนต์เริ่ม และไบต์ของตัวอักษรตัวแรกในฟอนต์ (มักเป็น 20 คือช่องว่าง) โปรแกรมจะวาดอักษรไทยทุกตัวในตารางอักษรลงช่องของไบต์นั้น ใช้ค่าสี ขนาดช่อง จากด้านบน

สร้างรอมภาษาไทยและแพตช์

แพตช์มีแค่ส่วนที่เปลี่ยน ไม่มีตัวเกม จึงแจกในเพจได้ คนเล่นต้องมีรอมหรือแผ่นต้นฉบับรุ่นเดียวกับที่คุณเปิดอยู่ รอมตลับใช้ .bps ส่วนแผ่น PS1 ใช้ .ppf และรวมทุกไฟล์ในแผ่นที่คุณแปลไว้

แปะแพตช์ลงรอม

เลือกไฟล์ .bps .ips หรือ .ppf โปรแกรมจะแปะลงรอมหรืออิมเมจแผ่นที่เปิดอยู่ ตรวจความถูกต้อง แล้วบันทึกผลลัพธ์

ใส่เครดิตเพจบนหน้าไตเติลของเกม

หาภาพหน้าไตเติลในรายการ คลิกบนภาพตรงที่อยากวางเครดิต แล้วกด "ใส่กลับลงรอม" เครดิตจะถูกรวมตอนสร้างแพตช์ เกม GBA และ DS มักบีบอัดภาพไว้ (LZ77) โปรแกรมค้นหาและบีบอัดกลับให้ ส่วนเกมที่ไม่บีบอัด เช่นไฟล์ภาพ TIM ของ PS1 ให้ใส่ตำแหน่งเอง

ถ้าภาพดูเป็นชิ้นสลับกัน เกมนั้นใช้ไทล์ซ้ำกับแผนที่ไทล์ เครดิตจะไปโผล่ทุกจุดที่ไทล์นั้นถูกใช้ ให้วางทับไทล์ที่ใช้ที่เดียว เช่นตัวหนังสือ PRESS START หรือบรรทัดลิขสิทธิ์ ลองปรับ "กว้าง" ให้ภาพเรียงตัวถูกก่อน
