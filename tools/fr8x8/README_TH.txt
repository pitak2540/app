แพตช์ช่องฟอนต์ 8x8 สำหรับ Pokemon Ultra Violet 1.22 (FireRed BPRE)
=====================================================================

ช่องใหม่
  F9 20 – F9 CF  = ช่องฟอนต์ 8x8 เพิ่ม 176 ช่อง (ช่องตัวอักษรเดิม 00–FF ใช้งานได้เหมือนเดิม)
  ภาษาไทยใช้ F9 + (0x20 + เลขท้ายยูนิโค้ด)  เช่น ก U+0E01 = F9 21, า U+0E32 = F9 52
  F9 80 ขึ้นไป  = รูปพิเศษ (วรรณยุกต์ตัวสูง, สระ/วรรณยุกต์ชิดซ้ายสำหรับ ป ฝ ฟ ฬ, ญ ฐ แบบตัดเชิง)
  ใช้ได้ในทุกฟอนต์ของเกม (ข้อความสนทนา, เมนู ฯลฯ) สีตามข้อความเดิมอัตโนมัติ

สิ่งที่แก้ในโค้ดเกม
  0x08005B80  ฮุก RenderText -> โค้ดใหม่ที่ 0x08C80000 (วาดฟอนต์ 8x8 พื้นโปร่งใส ให้สระ/วรรณยุกต์ซ้อนบนพยัญชนะได้)
  0x081EA6C4  ตารางฟังก์ชันความกว้างตัวอักษร (ให้ตัดบรรทัด/จัดกลางคำนวณความกว้างตัวไทยถูก)
  0x08C82000  รูปฟอนต์ 176 ช่อง x 16 ไบต์ (2bpp: 0=โปร่ง 1=ตัวหนังสือ 2=เงา)
  0x08C82B00  ข้อมูลช่องละ 4 ไบต์: ระยะเลื่อน, ตำแหน่ง Y, ตำแหน่ง X (มีค่าติดลบได้), ว่าง

ไฟล์
  Thai8x8_FireRed.tbl  ตารางตัวอักษร (อังกฤษเดิม + ไทย + คำผสมสระ/วรรณยุกต์ที่เลือกรูปให้อัตโนมัติ)
                       ใช้กับโปรแกรมที่จับคู่แบบยาวที่สุด (longest match) ได้เลย
  thai_codec.py        แปลงข้อความไทยเป็นไบต์เกม: python thai_codec.py "สวัสดีครับ"
  font8x8.png/.csv     ภาพฟอนต์ไว้แก้เอง (ขาว=โปร่ง เทาเข้ม=ตัวหนังสือ เทาอ่อน=เงา)
  font_tool.py         export / import ภาพฟอนต์เข้า ROM ที่แพตช์แล้ว
                         python font_tool.py export ROM.gba font8x8.png font8x8.csv
                         python font_tool.py import ROM.gba font8x8.png font8x8.csv ROM_ใหม่.gba
  patch.py             แพตช์ ROM ต้นฉบับใหม่ (ต้องมี pip install keystone-engine)
  build_font.py        สร้างฟอนต์ไทยชุดนี้ (อ้างอิงจาก GNU Unifont แล้วบีบลง 8x8)
  inject_test.py       สคริปต์ที่ใช้ใส่ข้อความทดสอบใน ROM DEMO

ข้อควรรู้
  - ตัวไทย 1 ตัว = 2 ไบต์ ข้อความแปลจะยาวกว่าต้นฉบับ ถ้าไม่พอที่ต้องย้ายข้อความไปที่ว่าง (repoint)
  - ำ จะถูกแตกเป็น ํ + า เสมอ (ตาราง .tbl จัดการให้แล้ว)
  - วรรณยุกต์มี 2 แบบ: แบบต่ำ (ไม่มีสระบน) และแบบสูง (มีสระบน) — .tbl / thai_codec เลือกให้อัตโนมัติ
  - ที่ว่าง 0x08C80000–0x08C82DBF ถูกใช้แล้ว อย่าเอาไปทับ
