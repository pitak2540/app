# 90S Thai ROM Studio

เครื่องมือของเพจ **90S Game** สำหรับทำแพตช์ภาษาไทยให้เกมยุคเก่า: แกะข้อความจากรอม แปลเป็นไทย ใส่กลับ สร้างแพตช์ ใส่เครดิตเพจ และทำปกเกม ทุกอย่างทำงานในเครื่องของผู้ใช้ ไฟล์รอมไม่ถูกส่งออกไปไหน

> โปรแกรมนี้ไม่มีไฟล์เกมใด ๆ แถมมาด้วย ผู้ใช้ต้องมีรอมหรือแผ่นของตัวเอง แพตช์ที่สร้างมีเฉพาะส่วนที่เปลี่ยน ไม่มีตัวเกม

## ดาวน์โหลด

| ไฟล์ | ใช้กับ |
|---|---|
| `90S Thai ROM Studio.exe` | Windows 10/11 (เปิดเป็นหน้าต่างแอปผ่าน Edge หรือ Chrome ที่มีในเครื่อง) |
| `90S Thai ROM Studio.apk` | Android 7 ขึ้นไป (รุ่นเล็ก ไม่มีตัวแปลออฟไลน์ในตัว) |
| `90S Thai ROM Studio.html` | ทุกเครื่องที่มีเบราว์เซอร์ ดับเบิลคลิกเปิดได้เลย |

รุ่น Android ที่มีตัวแปลออฟไลน์ในตัว (ประมาณ 250 MB) อยู่ที่หน้า Releases ถ้ามี

## ทำอะไรได้

- **แกะข้อความ** อังกฤษ ญี่ปุ่น (Shift-JIS / EUC-JP) จีน เกาหลี และภาษายุโรป พร้อมหาพอยน์เตอร์
- **ระบบที่รองรับ** GBA, แผ่น PS1 (.bin / .iso), Nintendo DS, N64, Famicom, Super Famicom, Game Boy, Mega Drive, Master System, Game Gear, PC Engine, WonderSwan, Neo Geo Pocket และชุดรอมอาร์เคด .zip ความสามารถต่างกันตามระบบ ดูรายการ "ระบบที่รองรับ" ในโปรแกรม
- **แปล** พิมพ์เอง, เติมจากพจนานุกรมในตัว, แปลร่างคำต่อคำแบบออฟไลน์, แปลออฟไลน์ด้วยโมเดล (อังกฤษเป็นไทย)หรือ Google Translate
- **ใส่กลับและสร้างแพตช์** .bps สำหรับรอมตลับ และ .ppf สำหรับแผ่น PS1 รวมถึงแปะแพตช์ .bps / .ips / .ppf
- **ฟอนต์** ดูกราฟิกในรอมและวาดอักษรไทยลงฟอนต์ที่ไม่บีบอัด
- **แตกแพตช์ที่มีอยู่** แท็บแพตช์: ลงแพตช์ .bps / .ips แล้วแยกส่วนที่แก้เป็นข้อความ รูป/ฟอนต์ พอยน์เตอร์ ใช้รอมที่ลงแพตช์แล้วทำงานต่อ และสร้าง .bps จากสองไฟล์
- **ตารางอักษรไทยจากเกมที่แปลแล้ว** พิมพ์ประโยคไทยที่เห็นในเกม โปรแกรมจับคู่ไบต์ให้ (เติม TIS-620 ครบชุดในคลิกเดียวถ้าตรง)
- **แกะข้อความขั้นสูง** ไบต์ปิดข้อความหลายตัว (เว้นว่าง = เดาให้), ยอมให้มีรหัสคำสั่งในข้อความ, พอยน์เตอร์ GB/GBC (รวม text_far), NES, SNES LoROM/HiROM และกำหนดเอง ย้ายข้อความไปที่ว่างในแบงก์เดียวกัน
- **ฟอนต์** เลื่อนทีละไบต์/ช่อง ค้นไบต์จาก mGBA ฟอนต์ 8x16 ที่ครึ่งล่างอยู่แถวถัดไป แสดงรหัสอักษรและช่องว่าง ส่งออก/นำเข้า .png ไปแก้ในโปรแกรมวาดรูป
- **สร้างฟอนต์ไทยจากคลังฟอนต์ 90S Game** (20 ชุดที่ใช้จริงในเกมที่แปลแล้ว) หรือฟอนต์ในเครื่อง แบบช่องละพยางค์หรือแยกตัว เขียนลงช่องว่างและเพิ่มในตารางให้เอง
- **แท็บคลังฟอนต์** ดูทุกชุด ลองพิมพ์ประโยคเทียบ ส่งออกไทล์ .png / .bin กับ .tbl และ **แท็บคู่มือ** วิธีแปลเกมเองทีละขั้น
- **Pokemon FireRed ภาษาไทย** แท็บตารางอักษรมีปุ่มใส่แพตช์ช่องฟอนต์ 8x8 ให้ FireRed (BPRE) และแฮ็กที่ทำจาก FireRed US 1.0 เช่น Ultra Violet: เพิ่มช่องตัวอักษร 176 ช่อง (`F9 20`–`F9 CF`) พร้อมฟอนต์ไทยที่วาดไว้ สระและวรรณยุกต์ซ้อนบนพยัญชนะได้ และโหลดตารางอักษรให้พร้อมแปล
- **เครดิตในเกม** วางข้อความเครดิตบนภาพหน้าไตเติล (รองรับภาพที่บีบอัดแบบ LZ77)
- **ปกเกม** ทำปกพร้อมเครดิตเพจ บันทึกเป็น PNG

## วิธีใช้แบบย่อ

1. กด **เปิดรอม** แล้วเลือกไฟล์เกม
2. แท็บ **ข้อความ** เลือกภาษาต้นฉบับ แล้วกด **แกะข้อความ**
3. พิมพ์คำแปลในช่องด้านขวา หรือใช้ปุ่มช่วยแปล
4. แท็บ **แพตช์** กดบันทึกแพตช์หรือรอมภาษาไทย

## ตัวแปลออฟไลน์

ปุ่ม "แปลออฟไลน์ด้วยโมเดล" ใช้โมเดล [QuickMT en-th ONNX](https://huggingface.co/kaojai/quickmt-en-th-onnx) ซึ่งไม่ได้อยู่ใน repo นี้เพราะไฟล์ใหญ่ ให้ดาวน์โหลดทุกไฟล์จากหน้านั้น พร้อมไฟล์ `ort-wasm-simd-threaded.wasm` จากแพ็กเกจ `onnxruntime-web` 1.23.2 แล้วเลือกไฟล์ทั้งหมดในโปรแกรมครั้งแรกที่กดปุ่ม

## ข้อจำกัดที่ควรรู้

- ฟอนต์ไทยยังต้องทำเฉพาะเกม เครื่องมือในแท็บฟอนต์ใช้ได้กับฟอนต์ที่ไม่บีบอัดและช่องขนาดเท่ากัน
- คำแปลจากเครื่องทุกแบบต้องอ่านและแก้ก่อนใช้
- ไฟล์ .exe และ .apk ยังทดสอบบนเครื่องจริงไม่ครบ ถ้าพบปัญหาแจ้งได้ที่ Issues

## โครงสร้างซอร์ส

- `src/page.src.html` หน้าจอโปรแกรม, `src/core.js` `src/core2.js` แกนแกะและใส่ข้อความ แพตช์ และรูปแบบไฟล์ของแต่ละระบบ, `src/dict.js` `src/dict2.js` พจนานุกรม, `src/mt.js` ตัวแปลออฟไลน์
- `src/page2.js` ฟังก์ชันจากชุดแปลเกมเอง (แตกแพตช์ จับคู่ตารางไทย ฟอนต์ขั้นสูง สร้างฟอนต์ไทย), `src/fontdb.js` คลังฟอนต์ไทย 90S Game, `src/fontdb_page.html` หน้าคลังฟอนต์, `src/guide.html` คู่มือ
- `src/fr8x8.js` แพตช์ช่องฟอนต์ไทย 8x8 ของ Pokemon FireRed (โค้ดเกม ฟอนต์ และตารางอักษร)
- `src/build.py` รวมทุกไฟล์เป็น HTML ไฟล์เดียว
- `tools/thai-font-db/` สคริปต์ที่ใช้สร้างคลังฟอนต์ (อ้างอิง)
- `tools/fr8x8/` สคริปต์ Python ที่ใช้สร้างแพตช์ 8x8: วาดฟอนต์ (`build_font.py`), แพตช์รอม (`patch.py`), แปลงข้อความไทย (`thai_codec.py`), export/import ภาพฟอนต์ (`font_tool.py`) และไฟล์ `.tbl`
- `src/windows/` ตัวเปิดโปรแกรมบน Windows (Go), `src/android/` ตัวแอป Android (WebView)
